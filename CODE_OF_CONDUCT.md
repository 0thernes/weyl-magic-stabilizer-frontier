# Contributor Covenant Code of Conduct

We pledge to make participation in `weyl-magic-stabilizer-frontier` a harassment-free, intellectually rigorous, and welcoming experience for everyone, regardless of background or identity.

- **Standards:** Focus criticism strictly on mathematical arguments, formal proofs, code correctness, and reproducibility evidence. Give accurate attribution and state uncertainty honestly.
- **Unacceptable Behavior:** Harassment, personal attacks, fabricated verification claims, or willful misrepresentation of proof scope.
- **Contact:** Report concerns to Alexander Stephen Donahue at `0_0@0thernes.art`.
